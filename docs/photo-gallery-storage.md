# 写真ギャラリー / OneDrive 保存設計

## 方針

- 写真・画像の原本は OneDrive に保存する。
- Supabase には検索・分類・業務データ紐付け用の軽量なメタデータだけを保存する。
- アプリのギャラリー表示では OneDrive が生成するサムネイルを必要な分だけ取得し、原本を一覧表示時にダウンロードしない。
- 初期表示は36枚単位。大量の写真があっても一度にすべての画像を読み込まない。
- 1枚25MBまで、1回最大50枚を選択し、順番にアップロードする。

## 分類

- 茶摘み
- イベント
- 圃場
- 機械設備
- 作業記録
- 商品・制作
- その他

## OneDrive フォルダ

通常の写真:

`五代目八木一兵衛 / 07_写真 / 分類 / アルバム名 / YYYY / MM`

圃場に関連付けた写真:

`五代目八木一兵衛 / 04_圃場 / 圃場名 / 写真 / 分類 / アルバム名 / YYYY / MM`

機械設備に関連付けた写真:

`五代目八木一兵衛 / 05_機械設備 / 設備名 / 写真 / 分類 / アルバム名 / YYYY / MM`

## 権限

- `storage.view`: ギャラリー・写真台帳の閲覧
- `storage.upload`: 写真のアップロード
- `storage.manage`: Microsoft / OneDrive 接続設定

## 安全性

- OneDrive の原本削除操作はアプリには設けない。
- 同名ファイルは上書きせず OneDrive 側でリネームする。
- Microsoft のアクセストークンはブラウザへ保存せず、Edge Function が Vault 内の refresh token を使って必要時に取得する。
